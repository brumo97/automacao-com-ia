## Como repetir

Abra esta pasta no Cowork, disponibilize a skill `doc-transformer` e informe o documento e o formato desejado. Exemplo: “Transforme arquivos-testes/03-relatorio-projeto-elearning.docx em resumo executivo”.

A skill orienta salvar os arquivos em `resultados/`. E-mails e posts são previstos como texto no chat; há também um post salvo entre os resultados históricos. Os roteiros de slides são Markdown, não apresentações PowerPoint.
